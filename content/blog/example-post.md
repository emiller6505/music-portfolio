Welcome to my blog! This is an example blog post to show you how the markdown-to-HTML conversion works.

## Getting Started

You can write your blog posts in markdown format. The build script will automatically convert them to HTML and generate individual pages for each post.

## Features

- **Markdown Support**: Write in markdown, get beautiful HTML
- **Frontmatter**: Add metadata like title and date at the top of each post
- **Automatic Indexing**: All posts are automatically listed on the blog index page
- **Easy Publishing**: Just run `npm run build` and deploy the `docs/` folder

## Writing Posts

To create a new blog post:

1. Create a new `.md` file in the `content/blog/` directory
2. Add frontmatter at the top with `title` and `date`
3. Write your content in markdown
4. Run `npm run build` to generate the site

That's it! Your post will be automatically included in the blog index and available as its own page.

## Markdown Examples

You can use all standard markdown features:

- **Bold text**
- *Italic text*
- [Links](https://example.com)
- Lists (ordered and unordered)
- Code blocks
- And more!

Happy writing!
